# FairValue Football: web app

Next.js 16 (App Router) + TypeScript + Tailwind CSS v4 + shadcn/ui. Read-only: all data comes precomputed from the pipeline (see `docs/PRODUCT_SPEC.md`).

```bash
npm install
npm run dev        # http://localhost:3000
npm run lint
npm run typecheck
npm run build
```

Note: Next.js 16 differs from older versions. Check the bundled docs in `node_modules/next/dist/docs/` (see `AGENTS.md`).
